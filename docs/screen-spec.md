# 화면 명세 — 쿨다운 코파일럿

> 버전 1.0 · 2026-11-04
> 기능 동작은 `docs/feature-spec.md`, 화면 구성·문구·전환은 이 문서를 따른다.
> 기존 게임 앱 화면(점수 원형, 위반 카드, 주행 시작/종료 버튼, 대시보드·결과·기록)은 모두 폐기하고 새로 만든다.
> 가로형 차량 화면 기준. 실제 해상도별 레이아웃은 `[확인 필요]` (Pleos 디자인 가이드: Standard 14.6 / 17, Wide).

---

## 0. 원칙

| ID | 원칙 |
|---|---|
| UI-01 | 이 앱의 주 화면은 "화면 밖"이다. 개입은 공조와 음성 한 문장으로 하고, 화면은 정차 중에 결과를 보여 주는 곳이다 |
| UI-02 | 주행 시작·종료 버튼을 두지 않는다. 기어로 자동 전환한다 (D·R·N → 주행 중 화면, P → 리포트 또는 홈) |
| UI-03 | 주행 중 화면에는 입력 UI·숫자·스크롤을 두지 않는다 (SAFE-01). 상태 한 줄만 보여 준다 |
| UI-04 | 숫자보다 문장을 쓴다. 점수(0~100)는 화면에 내보내지 않고 "평소보다 차분했어요" 같은 비교 문장으로 바꾼다 |
| UI-05 | 학습하고 있다는 것을 보여 준다. 학습 진행, 배운 계절별 강도, "다음엔 덜 차갑게 할게요" 같은 문구로 개인화를 드러낸다 |
| UI-06 | 켜고 끄는 조작은 설정 한 곳에서만 한다. 홈은 상태를 보여 주기만 한다 |

## 1. 화면 목록과 흐름

| ID | 화면 | 열리는 때 | 주행 중 | DO 선언 |
|---|---|---|---|---|
| SC-01 | 온보딩 (3단계) | 첫 실행 1회 | 막힘 | 없음 |
| SC-02 | 홈 | 정차 중 기본 화면 | 막힘 | 없음 |
| SC-03 | 주행 중 화면 | 주행 시작 시 자동 | **표시** | `distractionOptimized="true"` |
| SC-04 | 주행 리포트 | 주행 종료 시 자동 (5분 이상 주행) | 막힘 | 없음 |
| SC-05 | 기록 | 홈에서 | 막힘 | 없음 |
| SC-06 | 설정 | 홈에서 | 막힘 | 없음 |

```
 첫 실행 ─▶ SC-01 온보딩 ─▶ SC-02 홈 ──(기어 D)──▶ SC-03 주행 중
                              ▲  │                       │
                              │  ├─▶ SC-05 기록 ─▶ SC-04 │(기어 P, 5분 이상)
                              │  └─▶ SC-06 설정          ▼
                              └────────(닫기)──────── SC-04 리포트
                                                  (5분 미만이면 바로 홈)
```

- 주행 중 화면이 아닌 화면은 AAOS UX 제한으로 주행 중에 막힌다. 막힘 화면 대신 SC-03으로 바꾸는 것은 앱이 화면 앞에 있을 때만 한다.
- 앱이 화면 앞에 없을 때도 C0·F1~F3는 포그라운드 서비스(`CopilotService`)에서 동작한다. 화면 유무와 개입은 상관없다.

## 2. SC-01 온보딩

정차 중에만 진행한다. 세 장 모두 버튼 하나 또는 둘, 본문 두 줄 이내.

| 단계 | 제목 | 본문 | 버튼 | 동작 |
|---|---|---|---|---|
| 1 | 평소보다 거칠어지면 차가 먼저 식혀 드려요 | 당신의 평소 운전을 배워서, 그보다 거칠어질 때만 공조를 살짝 조절해요. | 다음 | — |
| 2 | 공조를 자동으로 조절해도 될까요? | 온도는 최대 2℃, 바람은 한 단계까지만. 직접 만지시면 바로 손을 뗄게요. | 나중에 / 허용 | 허용: F2·F3 켬(F2-08) + `CAR_SPEED` 등 런타임 권한 요청. 나중에: F2·F3 끈 채로 시작 |
| 3 | 처음 5번은 배우는 중이에요 | 그동안은 아주 거친 운전에만 반응해요. 춥다면 "추워" 또는 "글레오, 너무 추워"라고 말해 주세요. | 시작하기 | 홈으로. 이 시점에 앱이 한 번 실행되므로 Gleo broadcast 수신 조건(F2-18)도 충족 |

- 진행 표시는 점 3개 (● ○ ○).
- 온보딩 중 주행이 시작되면 중단하고 SC-03으로 간다. 다음 정차 때 이어서 한다.

## 3. SC-02 홈

**레이아웃:** 왼쪽 정보 열(넓게), 오른쪽 상태 열. 오른쪽 위에 기록·설정 아이콘 버튼.

| 영역 | 카드 | 내용 | 보이는 조건 |
|---|---|---|---|
| 왼쪽 | 학습 진행 | "배우는 중이에요 · 3/5회" + 진행 막대 / 학습 완료 후 "당신의 운전을 알고 있어요" | 항상 (완료 후 7일이 지나면 숨김) |
| 왼쪽 | 지난 주행 | 시각·시간, 헤드라인 한 줄, 개입 요약 한 줄 ("쿨다운 1회 · 추워하셔서 바로 되돌렸어요") | 주행 기록이 있을 때. 누르면 SC-04 |
| 왼쪽 | 코스 브리핑 | "판교 → 수원 · 어려운 구간 2곳" + 듣기 버튼 | 목적지가 설정돼 있을 때 (F1) |
| 오른쪽 | 쿨다운 캐빈 | "켜짐 · 지금은 여름 모드 · 최대 −2℃" | 항상 |
| 오른쪽 | 피로 케어 | 켜짐 / 꺼짐 | 항상 |
| 오른쪽 | 음성 안내 | 켜짐 / 꺼짐 | 항상 |

- 오른쪽 카드는 상태만 보여 준다 (UI-06). 누르면 SC-06 설정의 해당 항목으로 간다.
- 권한이 없거나 공조 제어 미승인이면 쿨다운 카드에 "차량 권한이 필요해요"를 띄우고 설정으로 연결한다.

## 4. SC-04 주행 리포트

**레이아웃:** 왼쪽 결과, 오른쪽 추세. 오른쪽 아래 닫기.

| 영역 | 내용 | 규칙 |
|---|---|---|
| 헤드라인 | "평소보다 차분한 주행이었어요" / "평소와 비슷했어요" / "오늘은 조금 바빴네요" | 이번 주행 평균 공격성 점수와 최근 기준선 비교. 운전자를 탓하는 표현은 쓰지 않는다 |
| 숫자 3개 | 주행 시간 · 도와드린 횟수 · 어려운 구간 통과 | 어려운 구간은 F1 브리핑이 있었을 때만. 없으면 "최고 연속 차분 시간" |
| 개입 타임라인 | "18:52 · 4분 — 시원하게 해 드렸어요" / "19:10 — 추워하셔서 바로 되돌렸어요 · 다음엔 덜 차갑게 할게요" / "19:40 — 휴게소를 제안했어요 · 들르셨어요" | `InterventionEntity` 기준, 최대 4개. 강도가 바뀌었으면 문장 끝에 학습 결과를 붙인다 |
| 추세 | 최근 7회 막대 두 줄: 공격성, 피로 | 이번 주행 막대만 강조색. 축·숫자 없음 |
| 학습 상태 | 학습 모드면 "운전 습관을 배우는 중이에요 (3/5회)" | 학습 모드일 때만 |

- 5분 미만 주행은 저장만 하고 자동으로 띄우지 않는다. SC-05 기록에서는 볼 수 있다.
- 열린 상태에서 주행이 시작되면 SC-03으로 바뀐다.

## 5. SC-03 주행 중 화면

**레이아웃:** 가운데 아이콘 하나와 상태 문장 한 줄. 버튼·숫자·스크롤 없음. 터치는 무시한다.

| 상태 | 문장 | 아이콘 | 강조색 | 조건 |
|---|---|---|---|---|
| 평온 | 평온하게 주행 중 | 잎 | 기본 | 개입 없음 |
| 학습 | 운전 습관 배우는 중 | 반짝임 | 기본 | C0 학습 모드이고 개입 없음 |
| 쿨다운 | 시원하게 해 드리는 중 | 눈송이 | 청록 | F2 `STAGE1`·`STAGE2`·`RESTORING` |
| 환기 | 환기하는 중 | 바람 | 호박 | F3 공기 전환 |
| 휴게소 | 쉬어 갈 곳을 찾는 중 | 커피잔 | 호박 | F3 제안·경유지 추가 후 |

- 상태가 바뀔 때만 0.3초 페이드. 깜빡임·움직이는 애니메이션은 쓰지 않는다.
- 온도 숫자는 보여 주지 않는다. 차량 기본 공조 UI(GNB)에 이미 표시된다.
- `Activity`에 `distractionOptimized` 메타데이터를 선언하고, `CarUxRestrictionsManager`로 제한 상태가 바뀌어도 이 화면은 그대로 둔다.

## 6. SC-05 기록

- 최근 30회 주행 목록. 한 줄에 날짜·시간·헤드라인·개입 아이콘.
- 누르면 SC-04 리포트를 연다. 원시 센서 로그는 저장하지 않으므로(SAFE-05) 요약만 보여 준다.
- 맨 아래 "기록 전체 삭제" (확인 대화상자).

## 7. SC-06 설정

**레이아웃:** 왼쪽 기능 켜기·끄기, 오른쪽 "배운 내 취향".

| 영역 | 항목 | 형태 |
|---|---|---|
| 기능 | 쿨다운 캐빈 / 피로 케어 / 코스 브리핑 / 음성 안내 | 스위치 |
| 배운 내 취향 | 여름 · 봄가을 · 겨울별 현재 강도 문장 ("최대 −2℃ · 바람 · 통풍시트" / "최대 −1℃ · 바람" / "바람만 · 얼굴 쪽") | 읽기 전용 (F2-07) |
| 배운 내 취향 | 개인 기준 온도 ("여름엔 보통 24℃에 두세요") | 읽기 전용 |
| 초기화 | 운전 습관 다시 배우기 | 버튼 + 확인 대화상자. 기준선·강도·기준 온도를 지움 |
| 정보 | 데이터는 차 밖으로 나가지 않아요 (SAFE-05) | 문장 |

## 8. 시각 스타일

| 항목 | 값 |
|---|---|

| 아이콘 | 선 아이콘 한 종류로 통일 |

## 9. 결정 기록

| 결정 | 고른 안 | 뺀 안 | 이유 |
|---|---|---|---|
| 주행 중 화면 | 상태 한 줄 | 완전히 비우기, 점수 게이지 | DO 기준을 지키면서 한눈에 보임. 시연에서 개입이 보여야 함. 점수는 의식하게 만들고 주의를 분산시킴 |
| 주행 시작·종료 | 기어 자동 감지 | 버튼 | 입력 0 |
| 홈 기능 카드 | 상태만 | 홈에서 바로 켜고 끄기 | 홈은 정보 화면. 출발 직전 실수 방지 |
| 리포트 표시 | 5분 이상 주행 | 매번 | 짧은 이동 때 방해 |
| 리포트 추세 | 공격성·피로 두 줄 | 공격성만, 개입 횟수 | F2·F3 둘 다 핵심 기능 |
| 개입 문구 | 사람 말투 문장 | 수치 | 학습이 보이게 (UI-05) |
| 온보딩 | 3단계 | 1단계, 5단계 | 소개·동의·학습 안내가 각각 필요하고 그 이상은 이탈 |
| 강도 설정 | 학습 결과 보여 주기 | 직접 슬라이더 | 개인화가 제품의 핵심 |
| 테마 | 다크 + 주야간 자동 | 라이트 | 차량 환경·가이드 |
