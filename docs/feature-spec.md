# 기능명세서 — 쿨다운 코파일럿 (가칭)

> 버전 0.3 · 2026-11-03 · 게이트키퍼 제외, 기준선 학습(C0)·피로 케어(F3) 확정
> 수치(임계값·시간)는 초기값이며, 에뮬레이터 모의 주행으로 조정한다.

## 0. 전체 구조

```
 차량 데이터 ──▶ [C0 운전 패턴 엔진] ──▶ 공격성 점수 ──▶ [F2 쿨다운 캐빈]
 (차속·브레이크·조향·기어)   ▲   │                         └▶ 공조 제어
                         │   └──▶ 피로 점수 ────▶ [F3 피로 케어]
            개인 기준선 ─┘                              └▶ 공조 + 음성 + 경유지
 내비 경로 ───────────────────────────────▶ [F1 코스 브리핑] ─▶ 음성
 주행 기록 ───────────────────────────────▶ [F4 주행 리포트] ─▶ 정차 화면
```

| ID | 기능 | 동작 시점 | 운전자 입력 |
|---|---|---|---|
| C0 | 운전 패턴 엔진 (개인 기준선 학습) | 항상 (백그라운드) | 없음 |
| F1 | 코스 브리핑 | 출발 전(P단) + 어려운 구간 직전 | P단에서 시작 버튼 1회 (자동 시작도 가능) |
| F2 | 쿨다운 캐빈 | 주행 중 | 없음 |
| F3 | 피로 케어 | 주행 중 | "응/아니" 음성 한마디 (선택) |
| F4 | 주행 리포트 | 도착 후(P단) | 정차 중 터치 |
| S1 | 온보딩·설정 | 첫 실행, 정차 중 | 정차 중 터치 |

**주행 상태 판정:** 기어가 P가 아니거나 차속이 0보다 크면 "주행 중"으로 본다. 주행 중에는 화면에 입력 UI를 표시하지 않는다.

## C0. 운전 패턴 엔진 (개인 기준선 학습)

**목적:** "이 운전자에게 평소와 다른 운전"을 판단한다. 원래 운전이 시원시원한 사람과 조심스러운 사람에게 같은 기준을 쓰면, 한쪽은 계속 개입당하고 다른 쪽은 한 번도 개입을 받지 못한다.

### 입력 신호

| 신호 | 출처 | 주기 |
|---|---|---|
| 차속 | AAOS `CarPropertyManager` `PERF_VEHICLE_SPEED` | 변경 시 (약 10Hz) |
| 브레이크 페달 | `Brake.registerBrakePedalStatus` | 변경 시 |
| 조향각 | `SteeringWheel.registerSteeringWheelAngle` | 변경 시 |
| 기어 | `Gear.registerGearSelection` | 변경 시 |

### 추출하는 특징 (1초 단위로 계산, 최근 3분 창)

| 특징 | 계산 | 의미 |
|---|---|---|
| 급가속 횟수 | 가속도 > 기준선 상위 5% 값 | 거칠게 출발·추월 |
| 급감속 횟수 | 브레이크 ON이고 감속도 > 기준선 상위 5% 값 | 급제동, 앞차와 거리 부족 |
| 조향 변화율 | 조향각 변화 속도의 분산 | 잦은 차로 변경, 핸들 조작이 거칢 |
| 가감속 반전 | 가속↔제동 전환 횟수 | 정체 속 신경질적 운전 |

속도대(도심 0~60, 국도 60~90, 고속 90 이상)에 따라 정상 범위가 다르므로, **기준선은 속도대별로 따로 학습한다.**

### 학습 방식

| 단계 | 조건 | 동작 |
|---|---|---|
| 학습 모드 | 처음 5회 주행 또는 누적 60분 미만 | F2·F3는 일반 기본값 기준으로만, 보수적으로 개입. 특징 분포를 수집 |
| 개인화 모드 | 학습 모드 이후 | 속도대별 평균·표준편차를 기준선으로 사용. 점수 = 현재 값이 기준선에서 몇 표준편차 떨어졌는지 |
| 지속 갱신 | 주행이 끝날 때마다 | 지수이동평균으로 기준선을 천천히 갱신. **개입이 일어난 구간은 갱신에서 제외** (화난 운전이 "평소"가 되지 않게) |

- 모든 계산과 저장은 차량 안(온디바이스)에서만 한다. 주행 기록은 외부로 보내지 않는다.
- 저장: 주행별 요약 통계와 기준선 값만 저장한다. 원시 센서 로그는 저장하지 않는다.

### 출력

| 출력 | 범위 | 사용처 |
|---|---|---|
| 공격성 점수 | 0~100 | F2 |
| 피로 점수 | 0~100 | F3 |
| 주행 요약 | 주행 1회 | F4 |

## F1. 코스 브리핑

**목적:** 어려운 구간을 출발 전에 예습해서, 주행 중에 당황하거나 급하게 차로를 바꾸는 일을 줄인다.

### 흐름

1. 내비에서 목적지가 정해지면 (`onRouteStarted`, `onDestinationInfo`), 경로의 회전 안내 목록(`onTBTInfo`)과 정체 구간(`TrafficCongestionInfo`)을 받는다.
2. 어려운 구간을 고른다.

   | 유형 | 판정 규칙 (초기값) |
   |---|---|
   | 연속 분기 | 회전·분기 2개 이상이 500m 안에 연달아 있음 |
   | 복잡 교차로 | 회전 유형이 유턴·P턴·로터리이거나 5지 이상 교차로 |
   | 정체 진입 | 정체 구간이 시작되는 지점 |

3. **P단일 때만** 브리핑을 재생한다. 예: "오늘 길은 25분이에요. 12km 지점에서 분기가 두 번 연속 나와요. 두 번째는 오른쪽 2차로로 가세요. 그 뒤엔 정체가 3km 있어요." (30초 이내, 어려운 구간 최대 3개)
4. 주행 중에는 어려운 구간 **1km 전에 한 문장만** 말한다. 예: "곧 그 연속 분기예요, 오른쪽 2차로."
5. 브리핑 문장은 정차 중에 LLM으로 만들고, LLM을 쓸 수 없으면 템플릿으로 만든다.

### 예외
- 내비 안내를 받지 않는 주행: F1은 동작하지 않는다.
- 주행 중 재탐색(`onReRouteEnded`): 새 경로로 어려운 구간을 다시 계산하지만, 브리핑은 다시 하지 않고 직전 한 문장 안내만 한다.
- 내비 음성 안내와 겹침: 내비 안내를 우선한다. 우리 안내는 내비 안내 직후로 미루거나 생략한다.

## F2. 쿨다운 캐빈 — 공조 기능 상세

**한 문장 요약:** 운전이 평소보다 거칠어지면, 차가 말없이 실내 온도를 조금 낮추고 바람을 한 단계 올려 운전자가 진정하도록 돕고, 진정되면 원래 설정으로 되돌린다.

**왜 온도인가:** 더위와 공격성은 관련이 있다는 연구가 있다 (Kenrick & MacFarlane, 1986, *Environment and Behavior* 18(2): 기온이 높을수록 경적 사용이 직선적으로 늘었고, 창문을 열고 있던 운전자, 즉 에어컨을 쓰지 않던 운전자에게서 효과가 더 강했다). 시원한 바람은 말을 걸지 않고도 운전자의 상태를 바꿀 수 있는 수단이다.

### 동작 순서

| 단계 | 조건 | 공조 동작 | 운전자가 느끼는 것 |
|---|---|---|---|
| 0. 대기 | 공격성 점수 < 60 | 없음 | — |
| 1. 감지 | 공격성 점수 ≥ 60이 30초 이상 유지 | **현재 공조 설정 저장** (설정 온도, 바람 세기) | — |
| 2. 1차 개입 | 1단계 직후 | 설정 온도 **-1℃**, 바람 세기 **+1단** | 바람이 조금 세지고 시원해짐 |
| 3. 2차 개입 | 1차 개입 후 2분이 지나도 점수 ≥ 60 | 설정 온도 **-1℃ 추가** (원래보다 최대 -2℃) | 조금 더 시원해짐 |
| 4. 복원 | 점수 < 40이 5분 이상 유지 | 1분에 걸쳐 **저장한 원래 설정으로 복원** | 원래 상태로 돌아옴 |

### 안전장치

| 규칙 | 내용 |
|---|---|
| 변화 폭 상한 | 온도는 원래보다 최대 -2℃, 그리고 절대 최저 20℃. 바람은 최대 +1단 |
| 개입 빈도 상한 | 한 번 복원한 뒤 15분 동안은 다시 개입하지 않음 |
| 운전자 우선 | 개입 중에 운전자가 직접 온도나 바람을 바꾸면 **즉시 자동 개입을 멈추고 복원하지 않음** (운전자 설정을 존중). 이번 주행에서는 다시 개입하지 않음 |
| 공조 꺼짐 | 공조 전원이 꺼져 있으면 개입하지 않음 (갑자기 켜지면 놀랄 수 있음) |
| 미지원 차량 | `checkHvacTemperatureCapabilities`, `checkHvacFanSpeedCapabilities`로 확인해서 지원하지 않으면 F2를 끔 |
| 학습 모드 | 기준선 학습 중에는 일반 기본값 기준에서 더 높은 임계값(75)을 씀 |

### 투명성
- **첫 실행 때 정차 중에 동의**를 받는다: "운전이 거칠어지면 실내 온도를 1~2도 낮춰 드릴게요. 설정에서 끌 수 있어요."
- 개입하는 순간에는 말하지 않는다. 대신 **도착 후 리포트(F4)에서 알려준다:** "14:32에 3분간 시원하게 해 드렸어요."
- 설정에서 F2를 끄거나 강도(약하게 -1℃ / 보통 -2℃)를 고를 수 있다.

### 사용 API

| 동작 | API |
|---|---|
| 현재 설정 조회 | `HVAC.getHvacTemperature`, `getHvacFanSpeed`, `getHvacPowerState` |
| 변경 | `HVAC.setHvacTemperature`, `setHvacFanSpeed` |
| 운전자 조작 감지 | `HVAC.registerHvacTemperature`, `registerHvacFanSpeed` (우리가 바꾸지 않은 변경을 감지) |
| 지원 여부 | `checkHvacTemperatureCapabilities`, `checkHvacFanSpeedCapabilities` |
| 권한 | `CONTROL_CAR_CLIMATE`, `CAR_CLIMATE` — **Pleos App Market 사전 승인 필요** `[확인 필요]` |

**승인을 받지 못할 때의 대안:** 공조를 직접 바꾸지 않고, 정차 중(신호 대기 등 차속 0)에 "조금 시원하게 해 드릴까요?" 음성으로 제안만 하고, 운전자가 "응"이라고 답하면 실행한다. 이 경우에도 제어 권한은 필요하므로 최종 대안은 "도착 후 리포트에서 알려주기"뿐이다.

## F3. 피로 케어

**한 문장 요약:** 장거리 주행에서 조향이 평소보다 무뎌지고 들쭉날쭉해지면 졸음 신호로 보고, 외부 공기와 시원한 바람으로 먼저 깨운 뒤 다음 휴게소를 한마디로 제안한다.

| 항목 | 내용 |
|---|---|
| 감지 | C0 피로 점수: 연속 주행 시간 + 조향 미세 보정 패턴의 변화(기준선 대비) + 야간 시간대 가중치 |
| 1단계 | 피로 점수 ≥ 60: 공조를 외기 유입으로 바꾸고(`setHvacRecirculation`) 설정 온도 -1℃. F2와 같은 저장·복원·운전자 우선 규칙 적용 |
| 2단계 | 1단계 후 10분이 지나도 점수 ≥ 60: "2시간째 운전 중이에요. 12km 앞에 휴게소가 있어요. 들를까요?" |
| 응답 | "응" → 경유지로 추가 (`NaviHelper.addWaypoint`). "아니" 또는 무응답 → 30분 동안 제안하지 않음 |
| 재사용 | C0 엔진과 F2 공조 제어를 그대로 씀. 신규 개발은 피로 점수와 음성 응답 처리 |
| 확인 필요 | 다음 휴게소 위치를 얻는 방법 (NaviHelper에 POI 검색 API가 없으면, 경로 정보에서 휴게소 이름을 찾거나 문구를 "가까운 휴게소에서 쉬어 가세요"로 단순화) |

**F3를 고른 이유:** 기준선 학습(C0)이 공격성과 피로 두 가지 상태를 읽고, 공조라는 같은 수단으로 대응하는 구조가 된다. "평소의 나를 아는 AI가 상태에 맞게 실내를 바꾼다"는 하나의 이야기로 묶인다.

### 검토했지만 제외한 후보 (향후 확장)

| 후보 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 키즈 세이프 캐빈 | 뒷좌석 착석 감지(`Seat.getCurrentSeatOccupancy`), 도착 후 뒷좌석 확인 알림 | 사회적 가치가 크고 구현이 쉬움 | 기준선 학습과 연결되지 않음 |
| 웨더 프리셋 | 경로의 날씨 예보로 김서림 방지·전조등 미리 세팅 | 시연하기 좋음 | 외부 날씨 API가 필요하고, 차량 제어 권한이 추가로 필요 |

## F4. 주행 리포트

**표시 시점:** 주행이 끝나고 P단에 들어간 뒤. 정차 중에만 표시한다.

| 항목 | 예시 |
|---|---|
| 오늘의 안정도 | "평소보다 차분한 주행이었어요" (기준선 대비) |
| 개입 기록 | "14:32에 3분간 시원하게 해 드렸어요" (F2), "휴게소 제안 1회" (F3) |
| 어려운 구간 결과 | "브리핑한 연속 분기 2곳을 안정적으로 통과했어요" (F1) |
| 추세 | 최근 7회 주행의 공격성 점수 그래프 |
| 요약 문장 | 정차 중에 LLM으로 생성, 안 되면 템플릿 |
